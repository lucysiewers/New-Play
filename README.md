# Next Play

My app helps a game developer decide which game to make next by which genre is most highly rated, which genre has few games but lots of players, and which genre has the most players that play for a long time.

> A course project for **MIST 4600: Computer Programming in Business** at the University of Georgia's Terry College of Business (Fall 2026).

## Problem
My app solves the problem of what kind of game should game developers make next. They need to understand which genre or type of game is that most popular to give them a better understanding of which game to next develop. This is hard to decipher without my app because it is hard to go through all of the data and extract the variables you need, whereas that's what my app is attempting to do. 


## What it does
My app answers three questions:
1. **Sub-question 1:** Which genres have the best rated games?
2. **Sub-question 2:** Which genres have many players but few games?
3. **Sub-question 3:** Which games have the most players that play for a long time?


## Data
The [Steam Games Dataset](https://www.kaggle.com/datasets/artermiloff/steam-games-dataset) on Kaggle, collected in March 2025. The dataset is shared under the MIT License by its creator, artermiloff. This repo uses `steam_games.csv`, a smaller file made for the course: the 1,000 games with the most reviews.
